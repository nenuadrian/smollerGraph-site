    API docs from comments we already wrote

    smollerGraph's API docs, made by Doxygen from the comments already in its headers, built in Docker as CI builds them, and published on GitHub Pages from the public repository.

    2 November 2026 · Watch on YouTube

    smollerGraph gets API docs, without changing a comment. Doxygen makes a page for each class and file from the comments in the headers, and since ours start with two slashes, as Google's style guide writes them, a filter gives each one the third slash Doxygen reads. A Docker stage builds the docs on a clean Ubuntu, as CI does, and CI publishes them on GitHub Pages from the public repository, on each push to main.
