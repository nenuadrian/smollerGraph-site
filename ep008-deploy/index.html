    Deploying a graph database to a VPS with Docker

    smollerGraph on a VPS, sent over SSH and run with Docker Compose, with Caddy serving the page in front of the database.

    22 October 2026 · Watch on YouTube

    We put smollerGraph on a VPS with a small script, deploy.sh, which sends the committed code over SSH, and Docker Compose builds it there and runs it in two containers. Caddy serves the page and passes the API's requests on to sg serve, which nothing outside can reach. Then we open the UI from anywhere, walk the food chain, inspect a record and ask a question in Cypher, all on the server.
