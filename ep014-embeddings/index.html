    FastRP node embeddings in a graph database

    Node embeddings in smollerGraph with FastRP, as Neo4j's Graph Data Science library computes them, the most similar nodes by cosine, embeddings kept on disk, and a page that draws a node's nearest.

    1 November 2026 · Watch on YouTube

    We give each node of smollerGraph a vector of numbers that stands for where it is in the graph, with FastRP, the way Neo4j's Graph Data Science library does it: a sparse random vector for each node, then rounds in which each node's vector becomes the sum of its neighbours'. Two nodes with similar neighbourhoods get vectors that point the same way, which a cosine measures, so we can ask which species are most like the lion, from the graph alone. The embeddings go into a file of their own, and the page draws the nodes most like a node, the less alike further away. It's a vanilla version of what GDS offers, written to see how it works.
