    Packaging a C++ library for CMake FetchContent

    smollerGraph as a library another CMake project fetches, with its tests, tools and docs kept to its own build, its headers in include/smollergraph, a query in one call, a consumer project built in CI, and a version to pin.

    smollerGraph becomes a library that another CMake project can fetch with FetchContent, as it would fetch Abseil, and link. A small project of its own shows what that was like at first, with our tests, sg and the docs' theme coming along, 72 tests in its ctest, and a path that pointed into the other project. CI builds the consumer on each change, a decision record says why, and the release gets a version tag to pin, v0.20.0. nanoMMO, the MMO from the other series, is going to use it at some point, to check its game content as a graph.
