    Dijkstra's algorithm in a graph database

    Weighted relationships and cheapest paths in smollerGraph, with Dijkstra's algorithm and a priority queue, then from both ends, Kùzu's WSHORTEST in Cypher, and weights on the page.

    1 November 2026 · Watch on YouTube

    We give the relationships of smollerGraph's social graph a weight, as LDBC's Social Network Benchmark does in its cheapest path question, and find the path whose weights add up to the least, with Dijkstra's algorithm. A priority queue hands out the cheapest node left, which can't get any cheaper, so the search settles the nodes in the order of their cost. From one end, it settles most of the graph, so it runs from both ends, and we work out when it can stop. Cypher gets WSHORTEST, the way Kùzu writes a cheapest path, and the page draws each relationship's weight. It's a vanilla version of what Neo4j's libraries and Kùzu offer, written to see how it works.
