    Canvas vs SVG: drawing a Wikidata graph

    Mammals and birds from Wikidata in smollerGraph, with room in its records for real names and a label, and a page that draws what a query returns on a canvas, measured against SVG.

    24 October 2026 · Watch on YouTube

    We load a real graph into smollerGraph: the mammals and birds on Wikidata, 21,834 species, genera, families, orders and classes. Their names don't fit, so nodes and properties get records of 64 bytes, and nodes get a label, which our facts and our Cypher learn to read. The page we built would draw every node with SVG, so we redo it: it draws what a query returns on a canvas, with a table, a plan, a history, a search and an inspector, and the server says what each query cost. Then we measure SVG against a canvas in Chromium, from 500 nodes to 20,000.
