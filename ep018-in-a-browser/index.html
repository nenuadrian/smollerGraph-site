    Graph database in a browser

    smollerGraph's library compiled to WebAssembly with Emscripten, unchanged, so the explorer runs in a browser tab on a graph it builds from Wikidata's facts as the page opens, published with the API docs on GitHub Pages.

    18 November 2026 · Watch on YouTube

    smollerGraph runs in a web browser. Emscripten compiles the library to WebAssembly as it is, as it starts no threads, maps no memory, opens no sockets and keeps its records in fields of fixed widths, and its newer Clang finds five initializers to tidy up. A small C++ file gives JavaScript the questions sg serve answers, as JSON, and the explorer's page asks the graph in the page, which it builds from the Wikidata facts each time it opens. CI builds it in Emscripten's Docker image and publishes it with the API docs, so anyone can try queries, records and similar nodes without installing anything.
