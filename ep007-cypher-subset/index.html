Writing a Cypher query parser and planner in C++

A subset of Cypher for smollerGraph, from tokens to a parser, a plan and its rows, in sg query and in the UI.

22 October 2026 · Watch on YouTube

We teach smollerGraph a subset of Cypher, the query language Neo4j and Kùzu speak, starting from a lexer and a recursive descent parser for MATCH patterns and what they RETURN. A planner turns a pattern into steps named after Neo4j's operators, a NodeIndexSeek through our B+ tree when the start has a name, an AllNodesScan when it doesn't, and an Expand for each hop, and EXPLAIN shows them. An executor runs the plan, sg query prints the answers, and the UI gets a query box for the questions we asked Neo4j in episode one.
