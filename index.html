    smollerGraph: Building smollerGraph: A Graph Database from Scratch

    A graph database, from the bytes up.

    We're going to build a small graph database from scratch in C++: how it keeps nodes and relationships on disk, how it follows them from one to the next, and how a Cypher query becomes a plan that runs, measured against Neo4j and Kùzu, on the way to a knowledge graph that mvGPT can ask for facts.
