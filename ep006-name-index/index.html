B+ tree index in C++: finding a node by name

An index on names for smollerGraph, a B+ tree in pages through the buffer pool, so opening a graph no longer reads each node.

22 October 2026 · Watch on YouTube

We give smollerGraph an index on names, a B+ tree in a file of its own, read through the buffer pool, so opening a graph no longer reads each node to build a map of names in memory. Its leaves hold the names in order, the pages above them say which page holds which names, and splits grow it a level at a time. The graph finds nodes through it, the UI suggests names as they're typed, and we measure what the index gives and what it costs.
